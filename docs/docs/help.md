# 详细帮助

在 Telegram 中向 bot 发送 `/help` 也可以看到命令列表 (群组中的帮助消息会在 2 分钟后自动删除).
下文按功能详细说明. 约定:

- `<>` 表示必填参数, `[]` 表示可选参数
- 「回复」指用该命令回复某条消息
- 「群管理」的定义见 [简介](index.md#一些基本概念)
- 部分命令的可用性取决于部署者的配置, 文中会标注

## 基础

| 命令 | 说明 |
| --- | --- |
| `/start` | 私聊中显示菜单: 开源仓库、帮助文档、老婆管理、语录管理, 启用面板时还有管理面板入口 |
| `/help` | 显示命令列表 |
| `/ping` | 测试 bot 是否存活, 并显示响应延迟 |
| `/lang` | 私聊中切换个人语言; 群里由群管理切换本群语言 |
| `/id` | 显示当前聊天 ID 与你的用户 ID. 回复某条消息时, 还会显示被回复者的 ID |
| `/ip <IP 或域名>` | 查询 IP / 域名信息. 也可以回复一条包含 IP / 域名 / 链接的消息 |

## 群设置

### `/config`

群管理发送后会出现一排开关按钮, 点击切换, 最后点「保存设置」. 各开关含义:

| 开关 | 说明 |
| --- | --- |
| 每日老婆 | 是否允许使用 `/waifu` |
| 删除事件 | 自动删除入群 / 退群等 Telegram 服务消息 (需要 bot 有删除消息权限) |
| 语录置顶 | `/q` 记录语录时是否置顶被记录的消息 |
| 解除频道置顶 | 自动取消关联频道消息在群里的自动置顶 |
| 转换 b23 短链 | 把 b23.tv / bili2233.cn 短链还原为完整链接 |
| 解析插画链接 | 自动解析 Pixiv 等插画站及 Twitter / X 链接 |
| 随机涩图 | 是否允许 `/setu` |
| 捡瓶子 | 是否允许在本群 `/pickbottle` |
| AI 回复 | 是否允许 AI 在本群回复 (需部署者启用 AI) |
| 响应其他 Bot | AI 是否响应其他 bot 的消息 |
| AI 评论 | AI 是否对频道转发到群的消息进行评论 |
| 群组记忆 | AI 是否记录本群的上下文作为记忆 |
| 新人验证 | 是否开启入群验证, 详见下文 |

此外还有链接解析的单站点开关、验证方式等更细的设置, 需要在管理面板中配置. 点击 `/config` 消息底部的「在面板中配置」按钮, 或直接发送 `/panel`, 即可打开本群的面板页面 (需要部署者启用[管理面板](webapp.md)).

### `/panel`

群里发送后, 返回一个按钮, 点击后在 Mini App 中配置本群. 未启用面板时会提示「管理面板未启用」.

### `/botpromote` 与 `/botdemote`

把某人设为 / 取消「bot 管理员」. bot 管理员在这个群里拥有等同于群主的 bot 配置权限 (例如使用 `/config`), 但不会获得 Telegram 层面的管理员权限.

```text
/botpromote            # 回复某人
/botpromote 123456789  # 或直接给出对方的用户 ID
```

仅群管理可用.

### `/syncmembers`

同步群成员: 把数据库中已不在群里的人清理掉, 使 `/waifu`、词云等功能的数据更准确. 有冷却时间, 仅群管理可用.

## 语录

把群友的精彩发言记录下来, 之后可以随机翻出来回味.

### `/q` 记录语录

回复一条消息发送 `/q`, bot 会把该消息记为语录 (同时生成一张语录图), 并按设置置顶这条消息. 如果不想置顶, 发送 `/q nopin`.

- 同一条消息只能被记录一次
- 转发的消息会记在原作者名下
- 过长或非文本的消息无法生成语录图, 但仍然会被记录

### `/qrand` 随机语录

随机发送本群的一条语录, 附带一个跳转到原消息的按钮. 如果本群还没有语录会给出提示; 群管理把概率设为 0 或负数时此命令不响应.

### `/qp <概率>` 设置主动发送概率

群管理设置 bot 在群里「随机主动翻出一条语录」的概率, 取值 `0` 到 `1` 之间的小数 (大于 1 视作 1).

- `/qp 0.02` : 每条消息有 2% 的概率触发
- `/qp 0` 或任意负数: 关闭主动发送, 同时禁用 `/qrand`

### `/d` 删除语录

- 群里**回复**被记录的消息发送 `/d`, 或者 `/d <消息链接>`: 删除该语录
- 私聊发送 `/d <消息链接>`: 删除指定语录

语录的作者、记录者可以删除自己的语录; 群管理可以删除本群的任何语录. 消息链接形如 `https://t.me/群用户名/123`.

私聊 bot 发送 `/start`, 点「语录管理」可以分页查看自己的语录并点击序号删除.

### Inline 查询

在任意聊天框输入 `@bot用户名 q 关键词` 查询语录, 输入 `@bot用户名 q_<群ID> 关键词` 只查询指定群的语录.

## 每日老婆

### `/waifu`

抽取今天的「群友老婆」: 从本群数据库中记录的群友里随机抽一位. 同一天内重复使用会显示同一个人. 抽到后消息下方会有按钮:

| 按钮 | 作用 |
| --- | --- |
| 娶老婆! | 向对方求婚. 对方同意后双方结婚, 之后每天的老婆固定为对方 |
| 换一只 | 花费金币换一个老婆 (已结婚时不可用). 同一天换得越多越贵 |
| 离婚 | 解除婚姻关系, 会通知对方 |
| 移除 | 从本群的记录中移除这位群友, 用于清理已经不在群里的人 (需要确认) |
| 不要 @ 我 / 抽到我时 @ 我 | 控制自己被抽中时是否被 @ |

注意:

- 老婆只来自 bot 见过的群成员, 新群可以先让大家多发言, 或用 `/syncmembers` 同步
- 不支持与匿名管理员、频道身份等非真实用户结婚
- 一个人同一时间只能有一位老婆
- 群管理可以在 `/config` 中关闭此功能

### `/waifu_graph`

生成本群今日的「老婆关系图」, 需要部署环境安装 graphviz. 没有人抽过老婆时会给出提示.

私聊 bot 发送 `/start`, 点「老婆管理」可以查看自己的老婆信息.

## 漂流瓶

跨群的匿名漂流瓶. 所有群和私聊共用同一片大海.

| 命令 | 说明 |
| --- | --- |
| `/throwbottle <内容>` 或 `/bottle <内容>` | 扔一个瓶子 |
| 回复某条消息发送 `/throwbottle` | 把该消息的内容装进瓶子 |
| `/pickbottle` | 从大海里捡一个随机的瓶子 |

- 瓶子可以是文字 (小于 4096 字), 或图片、视频、音频、文件、动图 (可带文字说明)
- 扔瓶子和捡瓶子都消耗金币, 且短时间内连续操作会越来越贵; 金币不够时不能扔
- 捡到的瓶子下方有按钮: **扔回大海**、**销毁瓶子** (仅限自己的瓶子)、**举报瓶子**、**追寻踪迹** (查看是谁什么时候扔的)、**回复瓶子** (给瓶子主人寄回信, 可选匿名或公开)
- 群管理可以在 `/config` 中关闭本群的「捡瓶子」
- 瓶子内容对所有人公开, 请遵守规则. 管理员可封禁滥用者

## 头衔

给自己或别人一个群头衔.

### `/t [头衔]`

- 直接发送 `/t 我是猫猫`: 给自己设置头衔
- 回复某人发送 `/t 你是猫猫`: 给对方设置头衔 ("互赠头衔")
- 不带头衔内容时, 使用用户名或昵称作为头衔

bot 在群里是拥有「添加管理员」权限的管理员时, 会通过把对方设为管理员再设置头衔的方式实现, 此时对方获得的管理员权限由 `/sett` 决定 (默认没有任何权限). 否则会改用 Telegram 的「成员标签」功能. 群主的头衔无法修改.

### `/sett`

群管理设置 `/t` 给对方的管理员权限 (如修改信息、删除消息、置顶消息等), 点击按钮切换. **请谨慎授予权限**: 任何人都可以用 `/t` 给自己一个带这些权限的头衔.

### `/td`

删除你自己的头衔.

## 新人验证

群管理在 `/config` 中打开「新人验证」后, 新成员入群时会先被限制发言, 需要在限定时间内完成验证, 否则被处理.

详细选项在管理面板中配置:

| 选项 | 说明 |
| --- | --- |
| 触发策略 | `all`: 所有新入群的人都要验证. `first_message`: 对尚未通过验证的成员, 在其发出消息时触发 |
| 验证方式 | `math_easy` 简单算术; `math_hard` 微积分 / 线性代数 / 概率等数学题; `emoji` 点击指定表情; `sticker` 回复一张贴纸; `custom_qa` 自定义问答 (可单选 / 多选) |
| 最大尝试次数 | 1 ~ 10 次, 默认 3 |
| 超时 | 30 ~ 600 秒, 默认 120 |
| 失败处理 | `kick` 移出群聊; `ban` 封禁; 或放行 |

管理员也可以在验证消息上直接放行或封禁对方. 验证通过后会恢复该成员原有的发言权限.

## 其他群管理

### `/greet`

设置新成员入群时的欢迎语.

```text
/greet set 欢迎 ${user} 加入 ${chat}!
/greet show
/greet remove
```

- `${user}` 会被替换为新成员, `${chat}` 会被替换为群标题
- 可以使用 HTML 标签, 欢迎语最长 1024 字符
- 仅群管理可用

## 链接解析与转换

这些功能不需要命令, bot 在群里 (或私聊中) 看到链接时自动处理.

| 来源 | 行为 | 需要的配置 |
| --- | --- | --- |
| Pixiv、B 站动态 / 专栏、Danbooru、Kemono、yande.re、nhentai | 解析为图片 + 作品信息 | 部署者配置了 ManyACG; 群里开启「解析插画链接」 |
| Twitter / X | 发送推文文字与图片、视频 | 群里开启「解析插画链接」 |
| 酷安、百度贴吧 | 发送帖子文字与图片 | 默认开启, 可在面板中按站点关闭 |
| 微信公众号文章 | 以富文本消息还原文章 | 默认开启, 可在面板中关闭 |
| b23.tv / bili2233.cn 短链 | 回复完整的 bilibili.com 链接 (已去除追踪参数), 并在群里删除原消息 | 群里开启「转换 b23 短链」 |

链接解析的总开关和各站点开关都可以由群管理在面板中调整.

## 其他实用命令

### `/wordcloud`

根据最近约 200 条消息生成词云图. 回复某条消息发送, 则统计该消息之前的 200 条. 白天 (6~18 点) 为白底, 夜晚为黑底. 仅群组可用.

### `/f5avatar`

bot 缓存了用户头像 (用于语录图、关系图等), 换了头像后发送 `/f5avatar` 强制刷新. 5 分钟内只能刷新一次.

### `/infographic <语法>`

把信息图语法渲染成图片, 也可以回复一条文本消息来渲染. 需要部署者配置 infographic 服务, 否则无响应.

### "施法"

不是命令: 以 `/` 或 `\` 开头发送一句话, 就能对别人或自己"施法".

| 你发送 | 效果 |
| --- | --- |
| 回复某人: `/揉` | A 揉了 B ! |
| 回复某人: `\揉` | A 被 B 揉了 ! |
| 不回复: `/揉` | A 揉了自己 ! |
| 回复某人: `/揉 一下` | A 揉 B 一下 ! |

用 `\` 可以反转主动与被动关系. 如果动作是纯英文数字 (如 `/rub`), 会被当作命令而不触发; 用中文, 或写成 `//rub` 即可.

## 礼物与好感度

kmua 有一套简单的好感度系统, 好感度会影响 AI 对你的态度, 也会影响 AI 把你暂时拉黑时的时长 (好感越高拉黑越短). 在**私聊**中使用:

| 命令 | 说明 |
| --- | --- |
| `/buygift` | 列出你当前买得起的礼物, 点击购买 |
| `/gift` | 把买到的礼物送给 bot |

礼物按稀有度分为凡芽、灵植、仪花、秘种、禁华. 各礼物的效果:

| 礼物 | 效果 |
| --- | --- |
| 默断之草 | 清空 bot 对你的记忆 |
| 誓印之莲 | 一段时间内显著避免好感度变动 |
| 苋色心灯 | 短暂地大幅提升好感度数值 |
| 低语霜花 | 查看 bot 当前对你的记忆 |
| 晓钟之草 | 解除被拉黑状态, 并在一段时间内免疫拉黑 |

金币通过发言、记录语录、"施法"以及每日奖励获得.

## AI 对话

需要部署者启用 AI (`agent = true`) 并配置模型接口.

**如何触发**

- 私聊 bot 直接发消息
- 群里回复 bot 的消息
- 群里在消息中提及 bot 的用户名或昵称

群管理可以在 `/config` 中关闭本群的「AI 回复」. 部署者可以用白名单只允许特定聊天使用.

**AI 能做什么**

AI 不仅是聊天: 它可以联网搜索与读取网页、处理图片、发送表情和贴纸回应、记住群里的内容、在 RSS 推送时生成摘要和播报, 以及对转发到群里的频道消息发表评论, 部署者还可以开放 shell 和工作区工具. 具体能力取决于部署者的配置.

| 命令 | 说明 |
| --- | --- |
| `/chat <内容>` | 显式向 bot 提问 (等同于对话) |
| `/forget` | 让 bot 忘记与你的对话记录 |
| `/quota` | 查看你和本群的 AI 使用额度. AI 按 token 用量计费, 先扣个人免费额度, 再扣群额度 |
| `/addsticker` `/delsticker` `/clearsticker` | 管理 bot 的表情包记忆: 让 bot 记住哪些贴纸可以在合适的时候发出来 (仅群组) |
| `/model` `/prompt` | 设置模型和系统提示词 (仅 bot 管理员) |

## 色图与随机头像

需要部署者配置 ManyACG 服务.

| 命令 | 说明 |
| --- | --- |
| `/setu` | 随机发一张图, 带作品链接和原图按钮. 有冷却时间. 群里需要群管理在 `/config` 中开启「随机涩图」 |
| `/randavatar` | 随机抽一张插画, 并自动裁出适合做头像的部分 (需要额外部署 aniobjcut 服务) |

## RSS 订阅

把 RSS / Atom 订阅推送到聊天里. 群里仅群管理可操作. 为避免滥用, 默认采用白名单: 只有 owner 在面板中放行的聊天才能订阅. 每个聊天最多订阅 20 个.

```text
/rss sub <feed URL>              订阅
/rss list                        查看订阅 (显示序号)
/rss unsub <序号>                取消订阅
/rss pause <序号>                暂停推送
/rss resume <序号>               恢复推送
/rss interval <序号> <分钟>      设置该订阅的抓取间隔, 留空恢复全局默认
/rss testpush <序号>             立即推送一次, 用于测试
/rss digest on|off               开关 AI 摘要 (需启用 AI)
/rss broadcast on|off            开关 AI 播报 (需启用 AI)
```

不带参数发送 `/rss` 会显示这份用法.

## 常见问题

**bot 不回应群里的普通消息 (语录、词云、链接解析都不工作)?**
检查 bot 的隐私模式是否已在 BotFather 中关闭, 并确认群是超级群.

**`/config` 提示没有权限?**
你需要是群主、拥有「添加管理员」权限的管理员, 或被 `/botpromote` 的人.

**`/waifu` 提示找不到其他群友?**
bot 只认识它「见过」的人. 让群友多发几条消息, 或用 `/syncmembers` 同步.

**命令列表以什么为准?**
以 bot 内的 `/help` 为准, 本文档可能落后于实际版本. 欢迎[贡献文档](https://github.com/krau/kmua-bot/tree/v2/docs).
