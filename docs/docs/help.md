# 详细帮助

在 Telegram 中向 bot 发送 `/help` 也可以看到命令列表. 下文按功能分类, 除特别说明外, 命令均可在群组中使用.

## 基础

| 命令 | 说明 |
| --- | --- |
| `/start` | 开始使用, 打开菜单 (私聊) |
| `/help` | 显示帮助信息 (群组中的帮助消息会在 2 分钟后自动删除) |
| `/config` | 更改 bot 在本群的设置 (群组) |
| `/panel` | 在[管理面板](webapp.md)中配置本群 (群组) |
| `/lang` | 切换语言, 私聊中设置个人语言, 群组中设置群语言 |
| `/id` | 获取聊天 ID |
| `/ip` | 查询 IP / 域名信息 |
| `/ping` | 测试 bot 是否存活及响应延迟 |

## 语录

| 命令 | 说明 |
| --- | --- |
| `/q` | 记录语录 |
| `/d` | 删除语录, 管理群语录 |
| `/qrand` | 随机语录 |
| `/qp` | 设置 bot 随机主动发送语录的概率 |

在任意聊天框中输入 `@bot用户名 q 关键词` 可以通过 Inline 模式查询语录.

## 群友互动

| 命令 | 说明 |
| --- | --- |
| `/waifu` | 抽取今天的群友老婆 |
| `/waifu_graph` | 生成老婆关系图 |
| `/wordcloud` | 根据聊天记录生成词云 |
| `/throwbottle` | 扔一个漂流瓶 |
| `/pickbottle` | 捡一个漂流瓶 |
| `/f5avatar` | 刷新你的头像 |

另外, 对他人的消息回复以 `/` 或 `\` 开头的文字即可对其"施法", 例如回复某人发送 `/揉`.

## 头衔

| 命令 | 说明 |
| --- | --- |
| `/t` | 获取头衔, 或与他人互赠头衔 |
| `/td` | 删除你的头衔 |
| `/sett` | 更改 `/t` 命令所赋予的权限 |

## 群管理

| 命令 | 说明 |
| --- | --- |
| `/greet` | 设置群欢迎语, 子命令: `set <欢迎语>` / `remove` / `show`, 欢迎语可使用 HTML, 变量 `${user}` 为新成员, `${chat}` 为群标题 |
| `/botpromote` `/botdemote` | 设置 / 取消 bot 管理员 (对 bot 而言, 该用户拥有等同于群主的权限) |
| `/syncmembers` | 同步群组成员 |

## AI 与内容

| 命令 | 说明 |
| --- | --- |
| `/chat` | 与 bot 对话 |
| `/forget` | 让 bot 忘记与你的对话记录 |
| `/quota` | 查看 AI 使用额度 |
| `/addsticker` `/delsticker` `/clearsticker` | 管理 bot 的表情包记忆 (群组) |
| `/setu` | 来点涩图 (需群组允许) |
| `/randavatar` | 随机头像 (依赖 ManyACG 配置) |
| `/infographic` | 渲染信息图 |
| `/rss` | 管理 RSS 订阅 |

## 礼物

私聊 bot 使用:

| 命令 | 说明 |
| --- | --- |
| `/buygift` | 购买礼物 |
| `/gift` | 送礼物给 bot |

## 仅 bot 管理员 / 所有者

| 命令 | 说明 |
| --- | --- |
| `/reload` | 重载配置文件 |
| `/status` | 查看 bot 的用户 / 群组 / 语录等统计 |
| `/model` `/prompt` | 设置 AI 对话使用的模型 / 提示词 |
| `/testverify` | 对目标成员立即触发一次入群验证 (调试用, 群组) |
| `/randmyavatar` | 立刻更换 bot 头像 |

部分命令的可用性取决于部署者的配置, 例如 AI 对话和涩图功能. 命令列表以 bot 内的 `/help` 为准.
